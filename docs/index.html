3. Năm đặc tính NIST

  1. On-demand self-service: Tự tạo Codespace mà không cần quản trị viên cấp phát máy.
  2. Broad network access: Truy cập API bằng máy tính và điện thoại thông qua URL HTTPS.
  3. Resource pooling: Codespace sử dụng tài nguyên được cấp từ hạ tầng dùng chung của nhà cung cấp.
  4. Rapid elasticity: Có thể nhanh chóng cấp phát, dừng và thay đổi cấu hình tài nguyên Codespace.
  5. Measured service: Theo dõi việc sử dụng tài nguyên trong mục Billing Usage.

4. Kết luận

GitHub Codespaces giúp tạo nhanh môi trường lập trình trên đám mây. Việc triển khai API không đòi hỏi tự cài đặt và quản lý máy chủ vật lý. Tài nguyên có thể được theo dõi và quản lý theo mức sử dụng.
